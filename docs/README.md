# ThreadLine documentation

ThreadLine is a local-first, read-only GitHub workspace organized around one selected repository. The current interface is in Simplified Chinese; user guides include matching interface labels where needed.

## Use ThreadLine

- [Getting started](getting-started.md): run the app, sign in, and choose a repository.
- [Using the workspace](workspace.md): understand lists and statuses, read PRs and issues, and manage local reminders.
- [Troubleshooting](troubleshooting.md): recover from connection, access, loading, and notification problems.
- [Data and security](data-and-security.md): understand permissions, credentials, local data, and cached content.

## Develop ThreadLine

- [Development](development.md): prerequisites, local commands, desktop builds, and contribution workflow.
- [Architecture](architecture.md): frontend, shared logic, desktop services, and persistence boundaries.
- [Testing](testing.md): automated checks and browser/native verification.
- [Repository instructions](../AGENTS.md): documentation language, commit conventions, and required verification.

## Maintain and distribute

- [GitHub App setup](github-app-setup.md): configure the shared read-only GitHub App or a fork's registration.
- [Development: builds and distribution](development.md): build installers and understand development-artifact limits.
