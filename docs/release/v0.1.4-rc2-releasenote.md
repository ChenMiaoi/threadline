# ThreadLine 0.1.4-rc.2

## Inbox read state

- Restore existing read markers when starting from cached records after an upgrade, including while synchronization is pending or offline. Migration no longer waits for a complete live refresh.
- Recover read markers even when the inbox checkpoint already uses the new record identifiers.
- Preserve unread state for genuine new comments, reviews, and code changes. Migrating unchanged records does not generate new-activity alerts or sounds.

## Background operation

- Closing the main window now hides it instead of exiting ThreadLine. Automatic refresh, snooze reminders, and notifications continue according to your settings.
- Restore the existing window from the tray icon or by launching ThreadLine again. Repeated launches reuse the running process.
- Fully exit from the tray menu or Settings → About & updates → Quit ThreadLine. Local changes are saved first; a save failure keeps the app running and brings the error into view.
- Restore the window from the macOS Dock and save before quitting from the application menu. Disable supported WebView background throttling to keep background tasks running.
- Translate tray actions with the selected interface language and clarify the close button's background behavior.

## Release notes and updates

- Give each RC its own release-note file, matching the complete release tag.
- Continue offering newer RC and stable versions to both stable and RC installations, with signature verification and downgrade protection. Existing RC1 installations can discover this RC2 through the in-app update check.

macOS packages are ad-hoc signed and are not notarized by Apple. macOS may require manual approval in Privacy & Security on first launch.
