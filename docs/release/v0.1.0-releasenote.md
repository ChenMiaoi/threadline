# ThreadLine 0.1.0

- Read GitHub pull requests, reviews, issues, discussions, file changes, and checks in a desktop workspace.
- Keep read markers, snoozes, appearance, and notification preferences locally.
- Narrow large repositories by update time, with explicit notices when search results are limited.
- Retry local data reads and saves without discarding unsaved changes.
- Check for signed updates, download with progress, and install when ready to restart.

ThreadLine accesses GitHub through its own read-only GitHub App. It does not post comments, submit reviews, or merge pull requests. Notifications require the application to be running. Update-enabled release builds require the release signing configuration.
