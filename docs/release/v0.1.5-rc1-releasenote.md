# ThreadLine 0.1.5-rc1

This release candidate focuses on synchronization reliability and a more consistent desktop interface.

## Synchronization and reminders

- Move desktop list synchronization into Rust so it does not depend on WebView timers while the window is hidden.
- Recover from offline periods and transient failures with bounded retries, shared GitHub API cooldowns, and catch-up after returning to the window.
- Persist pending reminders in SQLite, keeping system notification and sound acknowledgements separate. Retry failed delivery without repeating an already acknowledged channel.
- Defer reminders during quiet hours, respect snoozes and notification categories, and establish a silent baseline for the first observation or a changed search range.
- Keep read/unread tracking independent of system notification delivery and avoid duplicate activity toasts inside the application.

## Workspace and feedback

- Use the lower-right notice dock for errors, warnings, update notices, and one-off operation results. Keep notice actions usable while a dialog is open.
- Show test-notification progress and delivery feedback, and await macOS authorization and submission results.
- Render window controls in the shared HTML header. Place the brand icon and name in the sidebar, the repository in the middle of the header, and search and account actions on the right.
- Refine settings layouts, dropdown indicators, notification controls, inbox actions, pull-request timestamps, and detail tabs.
- Select today's contribution cell by default, change the selected date on click, and preserve calendar outlines.

## Upgrade and preview notes

- This upgrade migrates the local database to schema version 3. Older ThreadLine binaries cannot open the migrated database; retain a backup before upgrading if you need to return to an older version.
- Synchronization reconciles GitHub snapshots rather than receiving a live event stream. GitHub indexing delays and bounded search results can still delay or omit intermediate activity. Fully quitting the app or suspending the OS stops synchronization.
- System notification submission does not guarantee that a banner appears: notification permissions and Focus settings still apply. Delivery is at least once; a crash between OS acceptance and saving the acknowledgement can repeat a notification.
- Custom macOS window controls provide close-to-background, minimize, and maximize/restore. They do not reproduce the native green button's window-tiling menu.
- macOS packages are ad-hoc signed and are not notarized by Apple. macOS may require manual approval in Privacy & Security on first launch.
