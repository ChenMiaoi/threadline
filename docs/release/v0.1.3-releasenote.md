# ThreadLine 0.1.3

## Release candidate 0.1.3-rc.1

This candidate validates fixes made after the original 0.1.3 installers. It is a separate prerelease download and does not replace the existing 0.1.3 stable release or downgrade its update channels. Install the matching asset from this release to test the fixes.

- Sign the complete macOS application bundle with an ad-hoc identity and verify the standalone app, DMG contents, and updater archive before publishing. The original Apple Silicon package had an incomplete signature and the Intel package was unsigned.
- Fix startup of local builds without configured updater credentials.
- Preserve the login and cached records when token renewal encounters temporary server errors or rate limits.
- Retain successfully rotated credentials if subsequent identity or access validation temporarily fails, while keeping live workspace access checks.
- Recover workspace synchronization when the network returns, including an older request failing after reconnection, and coalesce repeated reconnect events.
- Add regression coverage and verify two app-only outage/recovery cycles on macOS without losing the signed-in account or cached PRs.

macOS packages are ad-hoc signed and are not notarized by Apple. macOS may require manual approval in Privacy & Security on first launch.

## Appearance and notifications

- Add separate interface, reading, and code typography controls with installed system fonts, font sizes, line spacing, and visual wrap width.
- Improve syntax highlighting and provide live appearance previews.
- Add optional notification sounds with three selectable tones and a preview action, respecting reminder categories and quiet hours.
- Move recoverable warnings into a lower-right floating panel that collapses when idle without shifting page content.

## Inbox and code review

- Exclude your own comments and reviews from new Inbox activity while preserving concurrent updates from other people.
- Group code-comment threads and replies beneath their formal review summary.
- Stop inferring reply recipients from the thread's root comment.
- Use compact version icons to distinguish current and outdated reviews, and highlight PRs requesting changes in yellow.
- Remove redundant next-action advice from the PR detail header.

## Profile, storage, and updates

- Fix duplicate scrollbars and blank space below the authored-PR list, keeping the app bar and sidebar stationary while scrolling.
- Preserve the profile dashboard layout during refresh and make the identity header more compact.
- Clarify installed-version and available-update information and actions.
- Refine disk-usage categories, reduce cached repository-list data, and add targeted cache cleanup and capacity limits.

## Documentation and publishing

- Refresh README screenshots, release badges, installation instructions, and workspace documentation.
- Add Bug report and Feature request forms and a pull request template.
- Automatically omit the source release-note title from published release bodies and updater notes, avoiding duplicate version headings.
