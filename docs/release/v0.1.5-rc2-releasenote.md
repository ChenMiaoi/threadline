# ThreadLine 0.1.5-rc2

This release candidate improves time handling, contribution calendars, and workspace interaction feedback.

## Time zones and contributions

- Add a display time zone setting that follows the system by default or uses a selected time zone. Time zone options include their UTC offsets.
- Apply the selected zone to timestamps and repository contribution dates for pull requests, issues, and reviews. Commit contributions retain GitHub's daily date buckets.
- Keep relative timestamps current while pages remain open and immediately catch up when returning to the window.
- Distinguish today, the selected date, and future dates in contribution calendars. Update the current day across midnight and the default year across New Year without requiring a page refresh.
- Use a compact calendar footer and subdued future-date cells.

## Workspace interactions

- Center filtered empty states in the available list area and center the GitHub connection screen. Add an explicit workspace entry after an account and repository are connected.
- Add lightweight feedback for controls, page regions, dialogs, PR previews, reminders, date selection, and expandable content. Avoid stacking parent and child fades.
- Enable motion by default for new workspaces and when restoring appearance defaults. Preserve saved preferences; Reduce motion and the system preference disable effects immediately, including exits already in progress.
- Complete dismissal animations without leaving interactive surfaces behind. Preserve keyboard focus after closing dialogs and avoid flashes when dismissing a surface during its entry animation.
- Retain search, filters, contribution year and date selections, and scroll positions when moving between pages during a session. Keep these choices isolated to the current account and repository.
- Wait for delayed list content before restoring scroll positions, and stop automatic restoration when the user starts interacting with the page.
- Retain loaded file differences when collapsing and reopening them, allowing height transitions without rendering the same content again.

## Upgrade and preview notes

- When upgrading from a version before v0.1.5-rc1, the local database migrates to schema version 3. Older binaries cannot open the migrated database; retain a backup if you need to return to an older version.
- Synchronization reconciles GitHub snapshots rather than receiving a live event stream. Fully quitting the app or suspending the OS stops synchronization.
- File-disclosure height transitions depend on embedded-browser support. Unsupported browsers retain the standard expand and collapse behavior.
- macOS packages are ad-hoc signed and are not notarized by Apple. macOS may require manual approval in Privacy & Security on first launch.
