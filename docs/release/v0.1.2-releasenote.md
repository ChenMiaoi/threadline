# ThreadLine 0.1.2

## Workspace

- Simplify GitHub sign-in and notification settings by removing redundant explanations and waiting messages.
- Keep native notification controls unavailable in browser previews without attempting desktop-only calls.
- Redesign repository selection around a single search field that also accepts a full repository name.
- Separate the sidebar's add-repository action from opening the current repository, and display its owner's cached GitHub avatar with the repository and owner on separate lines.

## Code review

- Show the relevant code diff, file location, and revision beside inline review comments.
- Wrap long diff lines visually at approximately 80 characters while preserving source line numbers.
- Increase code block and diff font sizes for easier reading.
- Collapse merged pull requests by default in the combined review list while keeping search results and explicit finished filters visible.

## Profile and storage

- Use the available profile page width and fit the contribution dashboard within one page on wide screens, while allowing scrolling on narrow screens.
- Move profile refresh beside the year selector and remove duplicate contribution headings.
- Add a disk usage panel showing application files, local data, cache, and browser storage estimates where applicable.
