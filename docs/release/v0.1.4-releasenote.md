# ThreadLine 0.1.4

## Release candidate 0.1.4-rc.1

This candidate replaces the withdrawn `v0.1.3-rc1` release with a version newer than `0.1.3`. Existing stable and RC installations can discover it through the application's update check.

## Updates

- Detect newer RC and stable releases from both stable and RC installations, including existing `0.1.3` installations. Both automatic and manual checks use this policy.
- Keep download and installation explicit, and preserve signature verification and version downgrade protection.
- Publish the same complete Windows and macOS update manifest at both existing update addresses, so older installations receive the same updates as new builds.

## Reliability and macOS packaging

- Sign the complete macOS application bundle with an ad-hoc identity and verify the standalone app, DMG contents, and updater archive before publishing.
- Fix startup of local builds without configured updater credentials.
- Preserve the login and cached records when token renewal encounters temporary server errors or rate limits.
- Retain successfully rotated credentials if identity or access validation temporarily fails, while keeping live workspace access checks.
- Recover workspace synchronization when the network returns, including an older request failing after reconnection, and coalesce repeated reconnect events.

macOS packages are ad-hoc signed and are not notarized by Apple. macOS may require manual approval in Privacy & Security on first launch.
