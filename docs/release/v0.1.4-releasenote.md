# ThreadLine 0.1.4

## Themes and appearance

- Add ten color themes, each with dark and light variants: ThreadLine, Rosé Pine, Catppuccin, Everforest, Nord, Graphite, Paper, Walnut, Ocean, and Carbon.
- Choose one theme at a time with an adjacent layout preview and labeled color swatches. System appearance and optional two-color gradients update the preview immediately.
- Preserve reference palette colors while adapting text for readability. Apply theme colors to icons, buttons, selected states, keyboard focus, toggles, code highlighting, and status indicators.
- Keep contribution-calendar cells square and use the theme accent for contribution intensity, legends, and the contribution breakdown chart.

## Inbox and background operation

- Restore existing read markers from cached records after an upgrade, including while offline or waiting for synchronization, without treating unchanged records as new activity.
- Keep background refresh, snooze reminders, and notifications running when the main window closes. Restore the window from the tray, macOS Dock, or another launch.
- Save local changes before quitting from the tray or application menu. Save failures keep the application running and show the error.
- Preserve login and cached records across temporary token-renewal failures, rate limits, and reconnects.
- Refine issue-list metadata and hide empty related-pull-request sections.

## Updates and packaging

- Show available updates in the floating notification dock without shifting the workspace layout.
- Offer newer release candidates and stable versions to existing installations, with explicit download and installation, signature verification, and downgrade protection.
- Publish installers and signed updater artifacts for Apple Silicon macOS, Intel macOS, and Windows x64.
- Verify macOS application signatures inside both installer and updater packages before publication.

macOS packages are ad-hoc signed and are not notarized by Apple. macOS may require manual approval in Privacy & Security on first launch.
