# Installing ThreadLine

Download the appropriate installer from the [latest release](https://github.com/ChenMiaoi/threadline/releases/latest):

- **macOS:** See [installing on macOS](macos-installation.md) for Apple Silicon and Intel downloads, installation, and updates.
- **Windows x64:** Download and run the `.exe` setup file.

After installation, follow [getting started](getting-started.md#sign-in-to-github) to sign in and select a repository. For development builds, see [development](development.md).
